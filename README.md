   # Bash Labs

   Репозиторий для лабораторных работ по Bash и Linux.

   ## 📜 Правила публикации работ (Workflow)

   Для поддержания чистоты и структурированности кода, каждая лабораторная работа ведется в отдельной ветке. Ветка `main` содержит только документацию и базовую конфигурацию (`.gitignore`).

   ### Алгоритм начала новой лабораторной:
   1. Переключиться на чистую главную ветку:
      ```bash
      git checkout main
      ```
   2. Создать и переключиться на новую ветку для конкретной лабы (например, `lab-03-01-variables`):
      ```bash
      git checkout -b lab-03-01-variables
      ```
   3. Выполнить задание, добавить файлы и сделать коммит:
      ```bash
      git add .
      git commit -m "feat: complete lab 03-01-variables"
      ```
   4. Отправить ветку в удаленный репозиторий:
      ```bash
      git push -u origin lab-03-01-variables
      ```

   ## 📂 Структура
   - `main` — основная ветка с документацией.
   - `lab-02-01-first-script` — первая лабораторная работа (создание и выполнение скриптов).
